# Flood Risk Assessment Survey

## Overview
This repository contains scripts to process, analyze, and visualize survey data on flood risk perception.
It includes steps for formatting survey responses, performing statistical tests, constructing a network of significant relationships, and generating figures and summary tables for publication.

## Quick Start
To run the full analysis, execute the following:

bash analysis.ps1

or:

powershell -c analysis.ps1

This will format the data, conduct statistical analyses, build a network of significant associations, and generate all figures and supplementary tables.

Note: Ensure Python 3 and required packages are installed (see requirements.txt).
